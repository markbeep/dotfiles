## Version Control Rules
- Always use `jj` (Jujutsu) for version control instead of `git`.
- Never execute raw `git` commands (such as `git add`, `git commit`, `git status`, `git branch`, or `git checkout`).
- Use `jj status`, `jj describe`, `jj diff`, `jj new`, `jj bookmark`, etc., for all repository and commit operations.
